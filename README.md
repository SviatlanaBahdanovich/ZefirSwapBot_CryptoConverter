# ZefirSwapBot Crypto Converter

A Telegram bot for converting currencies using exchange rates from an external API.

## Features

- Converts currencies using exchange rates from an external API.
- Supports several predefined currencies.
- Validates user input and handles errors.
- Provides help through the `/start` and `/help` commands.

Telegram bot: @ZefirSwapBot (https://t.me/ZefirSwapBot)
